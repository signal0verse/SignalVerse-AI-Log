# Prediction markets in the World ecosystem

## Metadata

- Date: 2026-11-25 (Asia/Kuala_Lumpur)
- Module: Prediction Market
- Mode: Read-only official documentation review
- Publication: SignalVerse-AI-Log, master

## Objective and findings

- World announced a [Polymarket Mini App](https://world.org/blog/announcements/polymarket-meets-world-wallet-with-new-mini-app) for countries where Polymarket can operate. The integration is an in-app handoff. Polymarket's [trading documentation](https://docs.polymarket.com/trading/overview) places matched-trade settlement on Polygon. World is another user entry point and does not resolve Polymarket's geographic restrictions.
- The [World ecosystem lists a Kalshi Mini App](https://world.org/ecosystem/app_a297091a4299bab011af3c3f7bd7d32c). [World Money's September launch announcement](https://world.org/blog/announcements/world-money) also references it and notes that eligibility varies by country. It provides access to Kalshi's event contracts. No authenticated availability was verified.
- [TickX](https://world.org/ecosystem/app_5613f2d20bf12c10b7c8a09d3cf97840) is listed as an on-chain price prediction game using World ID. The listing describes a grid-based game rather than an order book. [OracleX](https://chain.link/hack-26/projects/oraclex) is a World Chain hackathon project whose documented deployment uses mock USDC. Neither establishes a live, broadly usable event-market integration for SignalVerse.
- A native World Chain venue with verified liquidity, coverage, and a partner execution API was not identified in this review. No account, order, wallet, production, or application changes were made. This report is the sole deliverable.
